# 启动说明（conda `llm` 环境）

在本机 conda 虚拟环境 **`llm`** 中启动「AI 智行助手」。

> 本文档基于实测环境编写：conda 位于 `E:\Anaconda`，`llm` 环境位于 `E:\Anaconda\envs\llm`，Python 3.11.5。

## 1. 环境要求

| 项 | 要求 | 实测 |
|---|---|---|
| conda | 任意 Anaconda / Miniconda | `E:\Anaconda`（conda 25.11.0） |
| Python | ≥ 3.10 | llm 环境为 3.11.5 ✓ |
| 依赖 | 见 `backend/requirements.txt` | 已安装 ✓ |

## 2. 激活 llm 环境

**Anaconda Prompt / CMD：**

```bat
conda activate llm
```

**PowerShell：**

```powershell
conda activate llm
```

**Git Bash：**

```bash
source /e/Anaconda/etc/profile.d/conda.sh   # 按你的安装路径调整
conda activate llm
```

激活成功后命令行前缀会显示 `(llm)`。

## 3. 安装依赖（首次 / 依赖变更后）

```bash
cd "D:\Desk\项目\ai-travel-assistant"
pip install -r backend/requirements.txt
```

国内网络慢可加清华镜像：

```bash
pip install -r backend/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

依赖清单（实测安装版本）：

```
fastapi==0.110.0        uvicorn[standard]==0.27.1   openai==1.13.3
requests==2.31.0        pydantic==2.6.3             python-multipart==0.0.9
# openai 会自动带入 httpx 0.28.x（见第 6 节注意事项）
```

## 4. 启动服务

在已激活 `(llm)` 的终端、项目根目录下执行：

```bash
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --app-dir .
```

看到如下输出即启动成功：

```
INFO:     Started server process [xxxx]
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

浏览器打开 **http://localhost:8000/**。

> Windows 下也可以直接双击 `start.bat`，但它**不会**使用 conda 的 `llm` 环境，
> 而是用 PATH 里默认的 Python。要用 `llm` 环境请按本文档手动启动。

## 5. 首次使用

1. 进入「设置」Tab。
2. 填写 **LLM** 凭据（API Key / Base URL / 模型名，默认 MiniMax-M3）→「测试连接」。
3. 填写 **高德** 凭据（Web 服务 API Key）→「测试连接」。
4. （可选）添加外部 MCP server。
5. 凭据保存在 `backend/config.json`，仅本机使用。

## 6. 停止服务

在运行 uvicorn 的终端按 `Ctrl + C`。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `端口 8000 被占用` | 换端口：`--port 8001`，或先关掉占用进程 |
| `TypeError: ... unexpected keyword argument 'proxies'` | openai 1.13.3 + httpx 0.28+ 的已知冲突；项目已在 `_build_http_client` 中绕过。**不要**升级 openai ≥ 1.20，除非先验证该问题 |
| `conda activate` 无效（Git Bash） | 先 `source <conda 路径>/etc/profile.d/conda.sh` 再 activate |
| 高德调不到 | Key 类型应为「Web 服务」Key，不是「Web 端 JS API」Key |
| 前端 Markdown 不渲染 | marked.js CDN 被墙时，改为本地 `frontend/assets/marked.min.js` |

## 8. 安全提醒

- `backend/config.json` 含**明文 API Key**，已在 `.gitignore` 中忽略；**不要**提交进 git 或外传。
- 日志与错误信息中不会、也不应打印 api_key 明文。
