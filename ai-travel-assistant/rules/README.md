# rules/ — 项目规则索引

本文件夹把 `CLAUDE.md` 与 `AGENTS.md` 中的规则按主题拆分成独立文件，方便按需查阅。
所有规则源自项目根目录的两份权威文档，此处仅做归类整理，**以原文档为准**。

每个任务级规则文件（01–08）头部都有 `paths:` frontmatter，标明该规则对哪些文件生效；
`"**/*"` 表示全局适用。

| 文件 | 内容 |
|---|---|
| [01-项目概览.md](./01-项目概览.md) | 项目定位、技术栈、目录结构、启动方式 |
| [02-SSE协议与事件合约.md](./02-SSE协议与事件合约.md) | SSE 帧格式、事件类型、ReAct 步骤名、reasoning_split |
| [03-配置与安全.md](./03-配置与安全.md) | config.json 结构、API Key 处理、git 忽略约定 |
| [04-MCP规则.md](./04-MCP规则.md) | 外部 MCP 接入、命名空间、长连接缓存、协议握手 |
| [05-改代码硬约束.md](./05-改代码硬约束.md) | 模块职责切分、新增工具清单、Pydantic 约定 |
| [06-禁止事项.md](./06-禁止事项.md) | 红线清单（不要做的事） |
| [07-测试验证.md](./07-测试验证.md) | 手工验收清单 |
| [08-已知坑位.md](./08-已知坑位.md) | 常见报错与处理方式 |

> 改代码前先读对应主题文件；涉及流式协议时同时读 `02` 与 `frontend/js/app.js`。
