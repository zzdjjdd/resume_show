# 01 · 项目概览

## 项目是什么

**AI 智行助手** —— 端云协同的智能出行助手，单机演示级。

- **旅游模式**：用户填出发地/目的地/天数/人数/偏好，后端调用 LLM（默认 MiniMax-M3，可换任意 OpenAI 兼容模型），可选高德地图补全距离/天气，生成 Markdown 行程。
- **日常聊天**：多轮对话 + 流式输出 + 自动工具调用。最多 **5 轮**工具调用循环（地理编码 / 逆编码 / 天气 / POI 搜索 / 驾车/步行/公交路径 / 距离）。
- **设置**：在前端页面保存 LLM（API Key / Base URL / 模型名 / reasoning_split）与高德（SSE URL + API Key）凭据，写到 `backend/config.json`，仅本机使用。
- **外部 MCP 服务器**（聊天模式）：用户可在「设置」添加任意 MCP-over-SSE server（默认占位 12306 / 酒店），填入 URL 即可启用。

### 非目标（明确不做）

- 多用户、鉴权、生产部署、TLS、CORS 收紧。
- 引入前端框架或构建步骤。
- 替换 FastAPI / 替换 SQLite 等基础设施改动。

## 技术栈

| 层 | 选型 | 版本 |
|---|---|---|
| 后端框架 | FastAPI | 0.110.0 |
| ASGI | uvicorn[standard] | 0.27.1 |
| LLM SDK | openai（兼容任意 OpenAI 兼容端点） | 1.13.3 |
| HTTP 客户端 | requests / httpx | — |
| 校验 | pydantic | 2.6.3 |
| 表单 | python-multipart | 0.0.9 |
| 前端 | 原生 HTML/CSS/JS + marked.js（CDN） | 12.0.2 |
| 运行时 | Python ≥ 3.10 | — |

CORS 全放行（`*`），部署目标是单机演示。

## 启动

```bash
start.bat            # Windows：自动 pip install + 启动 uvicorn，端口 8000
# 或
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --app-dir .
```

前端访问 `http://localhost:8000/`，后端 API 同源。首次使用需在「设置」页填 LLM / 高德凭据并「测试连接」。
