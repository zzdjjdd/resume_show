# 06 · 禁止事项（红线）

- ❌ **不要把 `backend/config.json` 提交进 git 或复制出去**——它含明文 Key。
- ❌ **不要把 OpenAI SDK 升到 ≥ 1.20** 而不先验证 `proxies=` 报错是否还在
  （已在 `_build_http_client` 中绕过）。
- ❌ **不要在前端引入 React / Vue / 任何构建步骤**——这个项目刻意保持纯静态。
- ❌ **不要把 CORS 收紧到非 `*`** 而不同步改文档（演示用，全放行是有意的）。
- ❌ **不要在 `config.json` 里硬编码任何 MCP server URL**——它属于用户运行时数据，
  与 amap 的 `sse_url` 一视同仁。
- ❌ **不要把 `mcp_client._CLIENT_CACHE` 改成短连接**（每次 call 重连会慢得多），
  也**不要**在 `chat_stream` 退出时主动 close——下次请求复用。
- ❌ **不要把 `tool` 事件的 `server` 字段从 payload 里去掉**——前端 UI 依赖它展示 MCP 来源。
- ❌ **不要重构为新框架**（如换 React / 换 Litestar / 加 ORM）。本项目的简洁性是 feature，不是 debt。
- ❌ **不要去掉 ReAct 的 5 轮工具调用硬上限**（`ai_service.chat_stream` 内置，防死循环）。
- ❌ **不要手动往 `amap_service.MCP_TOOLS` 或 `_summarize_tool_result` 里加 MCP 工具**——
  外部 MCP 工具由 `mcp_client.load_mcp_tools()` 自动注入。
- ❌ **不要在日志或错误信息里打印 api_key 明文**。
