🔌 MCP 服务器（SSE-over-JSON-RPC）

通过标准 MCP 协议连接任意 MCP server。仅需填写服务 URL，工具列表由 server 自动声明。默认预填 12306（火车票）与酒店（搜索与推荐）两条占位，启用后会以 {name}__ 前缀暴露给 LLM。

📖 使用提示

  • 先到「设置」填写 LLM 与高德的凭据。
  • 「旅游模式」用于一次性生成可下载的 Markdown 行程表。
  • 「日常聊天」支持工具调用 — 例如询问"今天上海天气怎么样？"会自动调用天气接口。
  • 聊天模式下，单次对话最多可触发 5 轮工具调用。
  • 启用 MCP 服务器后，聊天时 LLM 会自动发现并调用其中的工具；调用结果会标注「🔌 来自 xxx MCP」。
