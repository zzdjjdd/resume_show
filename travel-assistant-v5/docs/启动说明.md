# 启动说明 · AI 智行助手

> 适用场景:**重启电脑后**或**首次运行**时,如何把项目跑起来。
> 操作系统:Windows(其他系统见文末「macOS / Linux」)。

---

## 方式一:一键启动(推荐,最省事)

重启电脑后,直接进入项目文件夹:

```
D:\Desk\项目\travel-assistant-v5
```

**双击 `启动.bat`** 即可。脚本会自动:

1. 检查是否安装了 Python(没装会提示);
2. 检查运行依赖,缺失时自动 `pip install`(仅首次约 1–2 分钟);
3. 启动后端服务。

看到下面这行就说明启动成功:

```
INFO:     Uvicorn running on http://0.0.0.0:8765
```

此时打开浏览器访问 **http://localhost:8765/** 开始使用。

> ⚠️ 运行期间请**保持这个黑色窗口开着**,关掉它服务就停了。

---

## 方式二:手动启动(命令行)

打开终端(PowerShell / CMD / Git Bash 均可):

```bash
# 1. 进入项目目录
cd "D:\Desk\项目\travel-assistant-v5"

# 2. 安装依赖(仅首次需要)
pip install -r backend/requirements.txt

# 3. 启动后端
python -m backend.app
```

同样看到 `Uvicorn running on http://0.0.0.0:8765` 即成功。

## 首次使用:先配置「钥匙」

服务起来后,打开 **http://localhost:8765/config**:

1. **LLM 模型服务**:填 `API Key` / `Base URL` / `Model`(点「获取模型」可下拉选择)→「测试连接」→「保存」。
   - 支持任意 OpenAI 兼容接口(OpenAI / DeepSeek / 硅基流动 / MiniMax 等)。
2. **高德地图 API**:填「Web 服务 Key」(到 https://lbs.amap.com/ 申请)→「测试连接」→「保存」。
3. **外部 MCP 服务 · 1 / · 2**(可选):填 MCP 端点 URL。
   - 服务 1 启用后,聊天时 LLM 可自动调用其工具(工具名加 `mc_` 前缀);
   - 服务 2 目前支持**保存与连接测试**,接入聊天为后续能力。

配置只保存在本地 `data/config.yaml`,不会上传到任何第三方服务器。

## 停止服务

- 在运行窗口按 **Ctrl + C**;或
- 直接关闭那个黑色命令行窗口。

## 常见问题

### 1. 启动报 `Errno 10048 / address already in use`(端口被占用)

说明上一次的进程没退干净,端口 8765 还被占着。处理:

```bash
# 查出占用端口的进程 PID(看最后一列数字)
netstat -ano | findstr :8765

# 结束该进程(把 <PID> 换成上一步查到的数字)
taskkill /PID <PID> /F
```

然后重新启动即可。

> 也可能是你同时开了两个启动窗口——关掉多余的,只留一个。

### 2. 报 `ModuleNotFoundError: No module named 'fastapi'`

依赖没装。执行:

```bash
pip install -r backend/requirements.txt
```

若提示 `pip` 不是命令,用 `python -m pip install -r backend\requirements.txt`。

### 3. 报 `'python' 不是内部或外部命令`

没装 Python 或没加入 PATH。到 https://www.python.org/downloads/ 安装 Python 3.10+,
安装时务必勾选 **「Add Python to PATH」**,装完重开终端再试。

### 4. 改了代码,页面没变化?

- 改了**后端**(`backend/` 里的 `.py`):必须**重启服务**才生效。
- 改了**前端**(`frontend/` 里的 HTML/CSS/JS):浏览器**强制刷新**(Ctrl + F5)即可。

### 5. 浏览器打开是空白 / 样式错乱

确认是通过 `http://localhost:8765/...` 访问(由后端托管前端),
而不是直接双击打开 `frontend/` 里的 HTML 文件。
