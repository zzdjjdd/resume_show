① LLM 模型服务

支持任意 OpenAI 兼容接口（含 DeepSeek、MiniMax、硅基流动等）。

点击「获取模型」可下拉选择；也可手动填入。

② 高德地图 API

用于路径规划、POI、天气、地理编码。可到 lbs.amap.com 申请「Web 端」Key。

本项目通过 REST API 直接调用，等价于 MCP 工具语义。
