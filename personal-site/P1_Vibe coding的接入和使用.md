# 第 1 讲 什么是 Vibe Coding

## 课件要点
- 字面意思：氛围编程
- 核心理念：在想象中编程
- 交互方式：大白话（自然语言）驱动
- **从“搬砖工”到“指挥家”的角色转变**

## 讲义展开
Vibe Coding（氛围编程）是一种全新的开发范式。它的核心在于：你不需要精通复杂的编程语法或系统架构，只需要清晰地表达你的想法。

**核心理念：**
1. **不设技术门槛**：不需要懂 Python、JavaScript 或 C++。AI 充当了翻译官，将人类的意图翻译成机器能理解的代码。
2. **想法即代码**：把你的想法告诉 AI，AI 负责将其转化为可运行的功能。这种方式极大地缩短了从“创意”到“产品”的距离。
3. **大白话编程**：使用自然语言进行沟通。如果你能把一个需求给同事讲清楚，你就能让 AI 帮你写出来。
4. **氛围感（Vibe）**：这不仅仅是写代码，更是一种“心流”体验。你关注的是逻辑、美感和用户体验，而繁琐的语法纠错交给 AI。

## 讲师提示
可以分享一个观点：未来的程序员可能不再是“写代码的人”，而是“定义问题并审核答案的人”。

# 第 2 讲 零基础的编程革命

## 课件要点
- 传统编程 vs Vibe Coding
- 学习成本与见效周期
- **“意图驱动” vs “语法驱动”**
- 为什么你完全可以学得会

## 讲义展开
### 1. 之前的编程方式（语法驱动）
在 AI 介入之前，想要开发一个功能，你需要：
- **漫长的学习曲线**：学习枯燥的语法基础（变量、循环、类、异步等）。
- **高昂的纠错成本**：一个分号的缺失可能导致程序崩溃，新手往往卡在环境配置和语法报错上。
- **经验依赖**：需要投入数月甚至数年的时间积累“坑”的经验，才能看到实际效果。

### 2. Vibe Coding 的优势（意图驱动）
- **零基础友好**：只要会打字、会表达，就能参与开发。AI 屏蔽了底层复杂性。
- **极速见效**：从想法到原型可能只需要几分钟。这种“即时反馈”是保持学习动力的关键。
- **低心智负担**：你关注的是“做什么”（What to do），而不是“怎么写”（How to code）。

## 关键对比
| 维度 | 传统编程 | Vibe Coding |
| :--- | :--- | :--- |
| 核心技能 | 记忆语法、逻辑严密 | 需求拆解、清晰表达 |
| 报错处理 | 查文档、搜 StackOverflow | 截图给 AI、描述现象 |
| 开发速度 | 慢（小时/天级） | 快（秒/分级） |

# 第 3 讲 核心能力：如何与 AI 对话

## 课件要点
- 提问与表达的艺术
- Prompt 工程（提示词工程）
- 上下文工程（Context Engineering）
- **Harness 工程：构建你的“测试场”**

## 讲义展开
在 Vibe Coding 时代，你唯一需要掌握的“硬技能”就是**如何更好地提问和表达**。

### 1. Prompt 工程：精准下达指令
不要只说“帮我写个网页”，要学会使用“角色+任务+约束+输出格式”的公式。
- **反例**：“写个个人主页。”
- **正例**：“你是一个资深前端设计师，请帮我用 Tailwind CSS 制作一个极简风格的个人主页。包含头像、简介、社交链接，配色方案要高级灰，且必须适配手机端。”

### 2. 上下文工程：让 AI 拥有“记忆”
AI 需要知道你现在的进度。在 Trae 或 Cursor 中，通过 `@` 符号引用特定的文件、文档或代码片段，让 AI 站在已有的基础上工作，而不是每次都从零开始。

### 3. Harness 工程：验证与闭环
AI 也会犯错。你需要学会如何构建一个“测试场”，通过运行代码、观察报错、反馈给 AI，形成一个自动修复的闭环。

# 第 4 讲 工具链准备：接入 AI 的大脑

## 课件要点
- API 购买与中转站：解决“大脑”来源
- 客户端配置：Cherry Studio 与 cc-witch
- **编译器三剑客：VSCode、Trae、Cursor**
- **如何选择适合自己的工具？**

## 讲义展开
要开启 Vibe Coding，我们需要准备好“大脑”（模型）和“手”（编辑器）。

### 1. 获取模型能力（大脑）
- **API 中转站**：推荐使用 [synai996.space](https://synai996.space/)。它整合了 GPT-5.4、Claude 4.5 Sonnet（目前编程最强模型）、Gemini 3.1 Pro 等。
- **为什么用中转站？** 门槛低、支付方便、一个 key 搞定所有顶级模型。

### 2. 客户端与编译器（手）
- **Cherry Studio / cc-witch**：适合作为“副驾驶”。当你需要咨询方案、解释代码或写文档时，它们非常方便。
- **Trae (字节跳动)**：**强烈推荐**。全中文界面，对国内开发者极其友好，内置了强大的 AI 代理模式。
- **Cursor**：目前全球最领先的 AI IDE，功能最全，但部分高级功能需要订阅。

### 3. 进阶工具：Agent CLI 安装
对于希望在终端直接与 AI 协作的用户，可以安装以下官方或第三方 Agent CLI 工具：

- **Claude Code (Anthropic 官方)**:
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
- **Gemini CLI (Google 官方)**:
  ```bash
  npm install -g @google/gemini-cli
  ```
- **OpenAI Codex / 相关工具**:
  ```bash
  # 使用国内镜像源安装以加速
  npm install -g @openai/codex --registry=https://registry.npmmirror.com
  ```

## 讲师提示
新手建议从 **Trae** 开始，因为它的中文适配和免费策略非常适合入门。

# 第 5 讲 实战演练：实现第一个个人定制网站

## 课件要点
- **需求拆解：从模糊到具体**
- AI 辅助生成：见证奇迹的时刻
- 预览与调整：如何进行“微调”
- **一键部署：让全世界看到你的作品**

## 讲义展开
我们将通过 Vibe Coding 实现一个个人定制网站。

**本次实战提示词记录：**
> 你好帮我写一个 个人网站，参考E:\第七期-Vibe Coding\MD部分\基础补足\Vibe coding的接入和使用\千城老师的介绍.txt，做一个精美可交换的网站，带有科技

**生成内容：**
- `个人网站/index.html` - 网站主页面，包含首页、关于我、竞赛成果、学术成果、技术栈等板块
- `个人网站/styles.css` - 科技风格样式，采用深色主题配合粒子动画背景
- `个人网站/script.js` - 交互效果，包括粒子动画、鼠标交互、滚动渐入等

**实战步骤：**
1. **明确需求**：我想做一个什么样的网站？（例如：一个带动态背景的个人简历，或者一个自动抓取天气预报的导航页）。
2. **开启对话**：在 Trae 的 `Builder` 模式下，直接输入：“帮我创建一个 React 项目，做一个深色模式的个人主页，要求有打字机效果的自我介绍。”
3. **迭代优化**：
    - “把背景换成星空流星效果。”
    - “在右下角加一个联系我的按钮，点击弹出二维码。”
4. **解决报错**：如果运行不起来，直接把报错信息复制给 AI，或者让 AI 自动扫描终端。

## 关键问题
在实战中，如果 AI 陷入了死循环（反复修改同一个地方但修不好），你应该如何通过“重置上下文”或“拆分任务”来引导它？
