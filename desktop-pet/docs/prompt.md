# Role
你是一位精通 Electron + Live2D 桌面应用开发的资深工程师，擅长制作高性能、低占用的桌面宠物程序。

# Task
请帮我从零搭建一个 Windows 桌面宠物 .exe 项目，角色形象为"圆脸微胖小美女侧面麻花辫牛仔背带裤可爱风"的 Live2D 模型。

# Tech Stack
- 框架：Electron (最新稳定版) + TypeScript
- 渲染：PixiJS v7 + pixi-live2d-display
- 构建：electron-builder (打包为便携版exe + 安装包)
- 样式：TailwindCSS (仅用于UI面板)

# Core Requirements
1. 【透明窗口】创建无边框全透明窗口，始终置顶，背景完全透明
2. 【鼠标穿透】角色模型区域可交互，空白区域鼠标事件穿透到桌面
3. 【拖拽移动】按住角色任意部位可拖动整个窗口位置
4. 【鼠标交互】
   - 鼠标悬停：触发开心表情 + 轻微摇晃动画
   - 点击头部：摸头动作 + 爱心粒子特效
   - 点击身体：害羞表情 + 后退半步
   - 鼠标移动：眼球和头部自然跟随鼠标方向（参数追踪）
5. 【闲置状态】无交互3秒后进入呼吸循环动画，30秒后触发随机小动作（打哈欠/整理辫子/看手机）
6. 【系统托盘】右键托盘图标显示菜单：显示/隐藏、重置位置、音量开关、退出
7. 【配置持久化】记住上次窗口位置和音量状态，下次启动自动恢复
8. 【资源管理】Live2D模型文件(.moc3/.json/纹理)从本地resources目录加载，支持热替换

# Output Format
请按以下结构输出：
1. 项目目录结构树
2. package.json 关键依赖及版本
3. main.ts 完整代码（含窗口创建、托盘、IPC通信）
4. renderer.ts 完整代码（含Live2D加载、交互逻辑、动画状态机）
5. electron-builder.yml 打包配置
6. 分步骤运行/调试/打包命令
7. 常见坑点及解决方案（如鼠标穿透失效、模型加载失败、打包后路径错误等）

# Constraints
- 代码需包含详细中文注释
- 内存占用优化建议（如离屏暂停渲染）
- 提供Live2D模型素材的规范说明（分层要求、参数命名约定）
